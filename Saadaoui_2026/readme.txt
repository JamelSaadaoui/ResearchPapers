Replication package for

Geopolitical Turning Points and Macroeconomic Volatility: A Bilateral Identification Strategy
Journal of Comparative Economics
Jamel Saadaoui (a,b)

March 28th, 2026

Code by Jamel Saadaoui (jamelsaadaoui@gmail.com)

(a) University Paris 8, Dionysian Lab of Economics, Institute for European Studies, 93200, Saint-Denis, France
(b) Centre for Applied Macroeconomic Analysis (CAMA), Australian National University (ANU), Australia.


***
The estimations have been conducted with Stata 19.5.

***
The folder contains the Stata program (Saadaoui_JCE_2026.do) to replicate all the figures and tables in the paper. Open this file in a folder with the data and run it.
You may want to change the current directory in line 14.

***
The Stata files Saadaoui_2026_JCE.dta provide the data to replicate all the figures and tables in the paper.
