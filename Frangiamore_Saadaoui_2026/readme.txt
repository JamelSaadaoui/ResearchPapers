Replication package for the paper "Local and Anglosphere-Based Geopolitical Risk and Sovereign Stress in the Euro Area" by Francesco Frangiamore (a) and Jamel Saadaoui (b) (2026)

April 26-th, 2026

(a) Department of Economics, Business and Statistics. University of Palermo, Italy. francesco.frangiamore@outlook.it; francesco.frangiamore@unipa.it
(b) Université Paris 8 Vincennes-Saint-Denis, LED, France and Australian National University, Centre for Applied Macroeconomic Analysis (CAMA), Australia, France. jamelsaadaoui@gmail.com

The analysis was conducted using R and RStudio:
R version 4.5.1
RStudio version 2025.09.2+418

The estimation uses the “lmtest” and “sandwich” packages. Please install these packages before running the code, if they are not already installed. To install a package, use install.packages("package_name").

The replication package contains two folders:

- paper: This folder contains the files needed to reproduce the figures in the paper. There is one folder for each figure, containing the dataset saved as an R file and the code required to reproduce the figure. Once the code is run, the figure will be displayed in the plot area in RStudio.

- appendix: This folder contains the files needed to reproduce the figures in the supplemental online appendix. There is one folder for each figure, containing the dataset saved as an R file and the code required to reproduce the figure. Once the code is run, the figure will be displayed in the plot area in RStudio. Figure A.17 is produced in Excel; therefore, the Figure A.17 folder contains the Excel file with the data and the plot.

In addition, the replication folder contains the dataset in Excel format, with two sheets: (i) one containing the data; and (ii) one containing information on the variables associated with the variable names in the dataset.
